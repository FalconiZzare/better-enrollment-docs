Errors are Better Auth `APIError`s carrying a `code` and a `message`:

```ts
import { INVITE_ERROR_CODES } from "@octopi-ai/better-enrollment";
```

## Errors from your own gates

Not every error from an invite endpoint is one of the codes below. When your own code rejects a user the plugin is creating, by returning an error from `user.validateUserInfo` (Better Auth 1.7) or throwing an `APIError` from a `databaseHooks.user.create.before` hook, that error reaches the caller unchanged, with your status and `code`. It is never rewritten into `EMAIL_ALREADY_INVITED` or `PRE_CREATED_USER_MISSING`. See [Gating invited users](/docs/recipes#gating-invited-users-with-validateuserinfo).

## Invite state

| Code                    | When                                                                                                                                                            |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `INVITE_NOT_FOUND`      | Unknown or no longer valid token                                                                                                                                |
| `INVITE_EXPIRED`        | The invite passed its `expiresAt`                                                                                                                               |
| `INVITE_REVOKED`        | The invite was revoked, or [withdrawn automatically](/docs/organizations#when-invites-are-withdrawn-automatically) because its inviter or invitee lost standing |
| `INVITE_ALREADY_USED`   | A single-use invite was already redeemed, or a public invite hit its use cap                                                                                    |
| `EMAIL_ALREADY_INVITED` | A pending invite of the same kind (and, for `org-join`, the same org) already holds that address; resend it                                                     |
| `USER_ALREADY_EXISTS`   | `app` invite to an address that already has an established account                                                                                              |
| `RESEND_TOO_SOON`       | `429`: the private invite was sent less than `resendCooldown` seconds ago                                                                                       |
| `EXPIRES_IN_TOO_LONG`   | `expiresIn` is above `maxExpiresIn`, or too large to be a date                                                                                                  |
| `MAX_USES_TOO_HIGH`     | A public invite's `maxUses` is above `maxPublicUses`                                                                                                            |

## Roles and permissions

| Code                            | When                                                                                                   |
| ------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `INVALID_ROLE`                  | Role rejected at create                                                                                |
| `ROLE_NO_LONGER_VALID`          | The invited role no longer exists at redeem                                                            |
| `ROLE_NOT_ALLOWED_FOR_ORG_JOIN` | `org-join` invites cannot set an app role                                                              |
| `NOT_ALLOWED_TO_MANAGE_INVITES` | Failed the admin gate (without the organization plugin, also any non-admin addressing an invite by id) |
| `ROLE_NOT_GRANTABLE`            | The creator or public-link resender may not [grant](/docs/permissions#granting-roles) that app role    |
| `ORG_ROLE_NOT_GRANTABLE`        | The inviter or public-link resender may not grant that org role                                        |
| `CANNOT_REDEEM_OWN_INVITE`      | Redeeming your own invite needs full authority over the roles it grants                                |

## Redemption guards

| Code                        | When                                                                                            |
| --------------------------- | ----------------------------------------------------------------------------------------------- |
| `PASSWORD_NOT_AVAILABLE`    | A password was sent to a [passwordless app](/docs/magic-link)                                   |
| `EMAIL_MISMATCH`            | Open-mode activation guard: the emails do not match                                             |
| `EMAIL_NOT_VERIFIED`        | Open-mode activation guard: the email is not verified                                           |
| `USER_BANNED`               | Banned accounts cannot redeem                                                                   |
| `INVITATION_REQUIRED`       | Verifying, signing in, or adding an account to a pre-created user before its invite is redeemed |
| `NAME_REQUIRED`             | Sign-up redemption without a name                                                               |
| `ADDITIONAL_FIELD_REQUIRED` | A required [additional field](/docs/options#additional-fields) is missing                       |
| `ADDITIONAL_FIELD_INVALID`  | An additional field failed its type check or validator                                          |

## Organizations

| Code                       | When                                                                                                                                                 |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SEAT_LIMIT_REACHED`       | No seats left: at create, resend of an expired invite, redeem, or the org plugin's invite-member / accept-invitation                                 |
| `MEMBERSHIP_LIMIT_REACHED` | The org plugin's `membershipLimit` is reached (only with `respectMembershipLimit`)                                                                   |
| `ORG_INVITE_NOT_ALLOWED`   | Not permitted to invite into that organization; with the organization plugin, also any invite id the caller may not manage, whether or not it exists |
| `ORG_DISABLED`             | The organization is disabled: create, redeem, and org members managing its invites or usage                                                          |
| `ORG_SLUG_TAKEN`           | Slug collision while founding an organization the founder names (preset slugs get a suffix)                                                          |
